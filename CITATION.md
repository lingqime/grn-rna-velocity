# Citation

The final manuscript citation metadata has not been inserted automatically
because the repository package does not establish the complete author list or a
final manuscript DOI/identifier.

Before public release, add a `CITATION.cff` containing the confirmed authors,
title, repository URL, release version/date, and manuscript DOI or preprint DOI
when available.

Until then, users of the RPE1 upstream data/software should cite the VeloCycle
publication:

Lederer, A. R. et al. Statistical inference with a manifold-constrained RNA
velocity model uncovers cell cycle speed modulations. *Nature Methods* 21,
2271--2286 (2024). https://doi.org/10.1038/s41592-024-02471-8
